# Smoke or Fire

The classic drinking card game, playable on any device. Built with Expo / React Native, deployed to web, iOS, and Android.

## Live

[smokeorfire.vientapps.com](https://smokeorfire.vientapps.com)

## Tech Stack

- React Native
- Expo
- TypeScript
- Firebase Realtime Database
- react-native-reanimated
